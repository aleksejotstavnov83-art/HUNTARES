# HUNTARES INTERNAL v3.0 — первая сборка (beta)

## Что действительно сделано

- Переведён нативный рендерер на `.so` вместо внешнего исполняемого процесса.
- Внутренний ImGui рисуется через EGL-хуки, перенесённые из присланных исходников Ximira.
- Добавлен Zygisk-модуль, выбирающий только `com.axlebolt.standoff2`, и APK-лоадер с кнопкой INJECT.
- Брендинг в меню — HUNTARES CHEAT / INTERNAL v3.0.
- Доступны отображение FPS, параметров рендера, статус хуков и экранный прицел.
- Офлайн-галерея скинов в APK сохранена.

## Что пока не работает

- ESP по игрокам, Chams, скинченджер и аимбот **не активированы**. Старый Ximira-профиль офсетов рассчитан на 1.0.0 и не проверен на 1.1.0. Нельзя включать чтение объектов с неподтверждёнными адресами.
- Работа меню внутри игры, установка Zygisk-модуля и компиляция на ARM64 ещё не проверены на телефоне.
- INJECT не выполняет прямую инъекцию. **Внедрение выполняет заранее установленный Zygisk-модуль**, когда стартует игра. Одна только установка APK не достаточна.
- Внутриигровой рендер может не появиться, если GLES/EGL не используется нужным способом или система блокирует хуки. Никаких SELinux-политик проект не меняет.

## Сборка в GitHub (с Android)

1. Распаковать исходный ZIP в корень GitHub-репозитория (как раньше через Termux `git add`, `git push`).
2. Перейти в Actions -> `Build HUNTARES INTERNAL v3` -> Run workflow, либо дождаться push.
3. После успешной сборки скачать артефакт `HUNTARES-INTERNAL-v30-APK-AND-MODULE`. В нём должны быть **два файла**: `HUNTARES_INTERNAL_v30.apk` и `HUNTARES_INTERNAL_v30_MODULE.zip`.

## Установка на устройстве

- Только устройство ARM64; root с KernelSU сам по себе не содержит Zygisk. Нужна совместимая реализация Zygisk, например Zygisk Next. Проверять версию и совместимость по официальной документации.
- Установить `HUNTARES_INTERNAL_v30_MODULE.zip` через модульный менеджер KernelSU/Magisk и перезагрузить телефон.
- Установить `HUNTARES_INTERNAL_v30.apk` и дать ему root для проверки присутствия модуля.
- Убедиться, что игра полностью закрыта, затем нажать INJECT: APK проверит наличие активного файла модуля и запустит игру; модуль загрузится только при новом запуске процесса.
- Для диагностики: `su -c 'logcat -d -s HUNTARES_INTERNAL'` через Termux; наличие соответствующих сообщений и ImGui-меню нужно подтвердить отдельно.
- Если не работает — отключить модуль в менеджере, перезагрузить телефон. Установка ни в коем случае не гарантирует ESP.

## Различия с прошлым проектом

Внешний BYCMD v2.1 не удаляется у тебя с телефона и не переносится автоматически в этот `.so`. v3.0 — **отдельная внутренняя ветка**, нельзя просто заменить ZIP в старом репозитории и ожидать тех же функций. Лучше создать новую ветку `internal-v3`.

## Источники и лицензии

- Внутренняя основа EGL/ImGui и интерфейса ввода перенесена из присланных пользователем исходников Ximira. Авторские пометки в файлах исходников сохранены.
- ImGui — сторонняя библиотека из того же присланного архива; сохраняется её license.txt, если она присутствует.
- Zygisk API `zygisk.hpp` загружается во время сборки из официального репозитория topjohnwu/zygisk-module-sample. Требуется доступ сборочного окружения к GitHub.
