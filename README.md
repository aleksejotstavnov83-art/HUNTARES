# HUNTARES CHEAT v1.9 — Skin Catalog & Visual Presets

Проект на базе предоставленных исходников BYCMD и HUNTARES v1.8, **не является написанным с нуля**. Внутри исходников сохранены исходные уведомления об авторах.

## Реально добавлено

- APK: кнопка **SKIN CATALOG** на заставке HUNTARES открывает автономную галерею, работающую без интернета. Поиск по названию, категориям, ID иконки; избранное и выбор предмета сохраняются в WebView.
- Использованы 2 662 уникальных позиции из пользовательского `bypess icons.zip` и `id.txt`; для части названий точного соответствия ID нет — они отмечены `ID: не сопоставлен`. Каталог содержит сжатые превью в WebP-атласах, без необходимости хранить 2700 отдельных PNG в Git.
- В нативном ImGui-меню: вкладка **Skin catalog** с поиском, категориями и сохранением выбранного индекса в `/data/local/tmp/huntares_skin_selection.txt` (требуется root, как и исходному HUNTARES). Это **локальная настройка каталога, не переключение скина в игре**.
- Visuals → Other: **Pearl / Ice / Rose / Gold / Mint** — мгновенно меняют цвета ESP-боксов и других элементов оверлея. Небо игры не изменяется.
- Исследовательская библиотека `research/visual_runtime/screen_geometry.*` сохранена как референс; пока не связана с ESP без подтверждённых координат костей.
- Название приложения/бинарника: HUNTARES CHEAT. Старый игровой функционал и попытка скрытия слоя от захвата оставлены как в v1.8, без гарантий работы на разных прошивках.

## Что НЕ добавлено

- Реальный скинченджер: каталог содержит только превью и ID иконок; код сетевой/игровой подмены скинов не содержится в представленных файлах.
- Замена часов, материалов неба, аимбот: `dumpzenin` содержит исследовательский код другого окружения, без подтверждённого переносимого адаптера к Standoff 2 1.1.0.
- Идеально точные боксы: по-прежнему используется оценочная высота тела, а не реальные кости.

## Обновление текущего GitHub-репозитория

Если у тебя старый проект в `~/HUNTARES_BYCMD_110_SOURCE_TEST`, скачай архив `HUNTARES_CHEAT_v19.zip` в Downloads и выполни:

```bash
cd ~/HUNTARES_BYCMD_110_SOURCE_TEST
unzip -o ~/storage/downloads/HUNTARES_CHEAT_v19.zip -d .
rm -rf native_bycmd
git add -A
git commit -m 'HUNTARES v1.9 skin catalog'
git push origin main
```

GitHub Actions установит Android NDK, соберёт и подпишет APK из текущего workflow. Ожидаемый артефакт `HUNTARES-CHEAT-APK-v19`. **В этом контейнере полный Android NDK отсутствует, поэтому сборка APK и запуск в игре не тестировались.**
